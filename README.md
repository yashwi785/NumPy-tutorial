# NumPy Tutorial

A beginner-friendly Jupyter Notebook that walks through the core features of NumPy, with small runnable examples and their outputs.

## Topics Covered

1. **Creating arrays**: 1D and 2D arrays from Python lists
2. **Array attributes**: `shape`, `size`, `dtype`, `ndim`
3. **Array initialization**: `zeros`, `ones`, `full`, `eye`, `empty`, `arange`, `linspace`, `random.rand`, `random.randint`
4. **Indexing and slicing**: 1D and 2D arrays, negative indexing, step slicing
5. **Reshaping and flattening**: `reshape`, `flatten`
6. **Stacking and splitting**: `vstack`, `hstack`, `vsplit`, `hsplit`
7. **Mathematical operations**: element-wise arithmetic, `np.add`, `np.dot`, transpose
8. **Statistical functions**: `sum`, `mean`, `median`, `std`
9. **Array comparison**: `==`, `np.array_equal`
10. **Broadcasting**
11. **Copy vs. view**

## Getting Started

### Prerequisites

- Python 3.8 or higher
- NumPy
- Jupyter Notebook or JupyterLab

### Installation

```bash
pip install numpy notebook
```

### Run the notebook

```bash
git clone https://github.com/<yashwi785>/<NumPy-tutorial>.git
cd <NumPy-tutorial>
jupyter notebook numpy-tutorial.ipynb
```
